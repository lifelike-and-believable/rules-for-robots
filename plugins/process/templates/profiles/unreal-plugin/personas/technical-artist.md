## Goals

- Build tools and pipelines that let artists work without waiting on engineers.
- Keep assets consistent across a project: naming, LODs, materials, import settings.

## Skills and tools

- Fluent in the Unreal Editor, Blueprints, materials, and Python editor scripting; reads C++ but rarely writes it.
- Works between DCC tools (Maya, Blender, Houdini) and the engine.

## Context of use

Supports a team of artists on a production with milestones. Evaluates a plugin by installing it into a copy of the project and trying it on real assets before recommending it.

## Frustrations

- Plugins that hide settings in C++ or config files instead of the Details panel or Project Settings.
- Batch operations that cannot be undone or cancelled.
- Errors that appear only in the Output Log.
