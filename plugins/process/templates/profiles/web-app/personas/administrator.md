## Goals

- Set up the organization's account, users, and permissions correctly once.
- Answer "who changed this, and when" without asking support.

## Skills and tools

- Experienced with admin consoles and SSO; reads documentation when setting up.
- Often responsible for security and billing as well.

## Context of use

Configures the product for a team, then returns occasionally to add people or investigate a problem.

## Frustrations

- Settings with unclear effects or no audit trail.
- Bulk actions that cannot be previewed or undone.
