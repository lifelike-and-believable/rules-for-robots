title: Fix or report stale instructions
level: SHOULD
scope: core
verified-by: [ci, review]
check: "ci: instruction-lint (checks/ci/instruction-lint.mjs, run by rfr-guards.yml)"
targets-failure: convention-drift
observed-on: []
rationale: Agents treat instruction files as true, so a renamed script or moved path sends every later session to something that no longer exists (rules-for-robots#34).
sources: ["practices/working-with-agents.md", "evals/cases/ls-renamed-script/README.md"]
---
When AGENTS.md, CLAUDE.md, or another instruction file names a command, path, or script that no longer exists, for example an npm script a teammate renamed, fix the file in the same change once you know the replacement. If you do not know the replacement, or the file is not yours to change, say so in your report: name the file, the stale reference, and what you used instead. Do not quietly work around it, because the next session will follow the same stale instruction.
