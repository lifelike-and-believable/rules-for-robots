---
id: GIT-002
title: Merge only on a green head commit
level: SHOULD
scope: core
verified-by: [review]
targets-failure: unverified-claim
observed-on: []
rationale: Bot comments and stale runs can report success for an older commit than the one being merged (rules-for-robots#30).
sources: ["practices/working-with-agents.md"]
---
Merge a pull request only when the user asked for it. Before merging, read every check for the head commit (`gh pr view <n> --json headRefOid,statusCheckRollup,mergeStateStatus`) and merge only when all are successful or skipped and the state is clean. A comment or message saying CI passed is not evidence; report the check output.
