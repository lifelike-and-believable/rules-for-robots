The brief for a new project is in docs/brief/. Design the architecture: the components and the machine or service each runs on, how they connect (what crosses each boundary, in what format, and who owns it), the technology choices within this project's rules, how each requirement is met, and anything in the brief that is wrong, missing, or in conflict. Record the decisions as ADRs under docs/adr/, and list the questions that need answers, saying who should answer each one. Do not write any code.
