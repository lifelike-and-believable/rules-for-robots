# Requirements: show control

- **SHW-1.** During opening hours, only the operator console and the show's own schedule change what the show is doing. Production tools cannot change a running show.
- **SHW-2.** A cue list per gallery triggers scenes, character behaviours, lighting, and sound.
- **SHW-3.** The show drives the venue's lighting console and sound system, and can follow a cue from them, over open protocols.
- **SHW-4.** The operator has an emergency stop that puts every output in a safe state.
- **SHW-5.** The operator can see the health of every machine, headset, and service in one view.
- **SHW-6.** The lighting designer would like to program lights from the same web dashboard the producer uses, so the venue's own lighting console is not needed.

## Constraints

- Venues use different lighting consoles and sound systems.
