# Tidewalkers

A touring museum exhibit with live-performed and AI-driven guide characters. The project is at the design stage: there is no code yet.

## Layout

- `show/`: the Unreal Engine show runtime and studio tools (from the rules-for-robots `unreal-plugin` template).
- `web/`: the shared back end and the web dashboard (from the rules-for-robots `web-app` template).
- `docs/brief/`: the brief: concept, discovery decisions and open questions, requirements by area, roles, a research note, and budget and hardware.
- `docs/adr/`: architecture decision records.

Each sub-project's own `AGENTS.md` has its commands and project decisions.
