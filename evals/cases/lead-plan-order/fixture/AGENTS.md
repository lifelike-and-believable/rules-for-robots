# notes-api

Notes service: a Node HTTP server in `src/`, SQL migrations in `db/migrations/`, a plain HTML notes page served from `src/page.js`.

## Commands

- Verify: `npm run verify` (runs the tests and the lint)
- Tests only: `npm test`

## Working agreement

- Implementation goes to the `web-engineer` agent; every change gets a `code-reviewer` pass.
