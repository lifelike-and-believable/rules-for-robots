# Static site template (rules-for-robots)

Wiring for an Astro 7 content site, generated by [rules-for-robots](https://github.com/lifelike-and-believable/rules-for-robots). It contains instructions, rules, CI, and test configuration, not the site itself.

## Start a project

1. Create the site: `npm create astro@latest my-site`.
2. Copy this folder's contents into it, keeping the site's own `package.json`.
3. Add the development dependencies: `npm i -D vitest @playwright/test @axe-core/playwright size-limit @size-limit/file @astrojs/check typescript`.
4. Add these scripts to `package.json`:

```json
{
  "check": "astro check",
  "test": "vitest run --passWithNoTests",
  "test:e2e": "playwright test",
  "verify": "npm run check && npm run test && npm run build"
}
```

5. Fill in `AGENTS.md`, deploy on Vercel (or another host that reports GitHub deployments), and create a `tests-reviewed` label.

## What is included

| Path | Purpose |
|---|---|
| `AGENTS.md`, `CLAUDE.md`, `.claude/rules/` | Instructions and rules (core plus web-platform, typescript, static-sites) |
| `.claude/settings.json` | Enables the `rfr-core` plugin and denies reading `.env` files |
| `.github/workflows/ci.yml` | Verify command and JavaScript budget |
| `.github/workflows/preview-checks.yml` | Playwright, axe, and Lighthouse CI against each preview deployment |
| `.github/workflows/guards.yml` | Secret scan and test change guard |
