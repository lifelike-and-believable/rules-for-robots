# RFR Cooldowns (rules-for-robots reference Unreal plugin)

Wiring for an Unreal Engine 5.6+ code plugin distributed on Fab, generated by [rules-for-robots](https://github.com/lifelike-and-believable/rules-for-robots). It contains the instructions, rules, CI, and verify script from the template, and the `RfrCooldowns` plugin built with them.

## RFR Cooldowns usage

`Plugins/RfrCooldowns` tracks named ability cooldowns for the game instance, so they survive map travel and cost nothing per frame.

- Blueprint: get the **Rfr Cooldown Subsystem** from the game instance and call `Start Cooldown`, `Is Cooldown Running`, `Get Cooldown Remaining`, `Clear Cooldown`, or `Clear All Cooldowns` (category **Cooldowns**).
- C++: `GameInstance->GetSubsystem<URfrCooldownSubsystem>()->StartCooldown(TEXT("Dash"), 2.f);`
- Cooldowns use real time (`FPlatformTime::Seconds`), so they keep running while the game is paused and ignore time dilation. A duration of zero or less clears the cooldown.

## Start a project

1. Create a host project and the plugin with the editor's plugin wizard (or copy an existing plugin into `Plugins/<Name>`).
2. Copy this folder's contents into the host project's root.
3. In `.github/workflows/tier1.yml` and `tier2.yml`, set the plugin folder, name, test filter, and copyright holder.
4. Fill in `AGENTS.md`: what the plugin does, supported engine versions, engine source paths, the copyright line, and the verify command (`./Scripts/Verify.ps1 -EngineVersion <v> ...`).
5. Register a self-hosted Windows runner with the labels `self-hosted, Windows, X64, ue5` on this repository (or its organization), with each supported engine installed. If engines are not in the Epic Games Launcher default folder, set repository variables `UE_5_6_ROOT`, `UE_5_7_ROOT`, and `UE_5_8_ROOT`.
6. Create a `tests-reviewed` label, and accept the `rfr-core` plugin in Claude Code when prompted.
