# Unreal plugin template (rules-for-robots)

Wiring for an Unreal Engine 5.6+ code plugin distributed on Fab, generated by [rules-for-robots](https://github.com/lifelike-and-believable/rules-for-robots). It contains instructions, rules, CI, and a verify script, not the plugin itself.

## Start a project

1. Create a host project and the plugin with the editor's plugin wizard (or copy an existing plugin into `Plugins/<Name>`).
2. Copy this folder's contents into the host project's root.
3. In `.github/workflows/tier1.yml` and `tier2.yml`, set the plugin folder, name, test filter, and copyright holder.
4. Fill in `AGENTS.md`: what the plugin does, supported engine versions, engine source paths, the copyright line, and the verify command (`./Scripts/Verify.ps1 -EngineVersion <v> ...`).
5. Register a self-hosted Windows runner with the labels `self-hosted, Windows, X64, ue5` on this repository (or its organization), with each supported engine installed. If engines are not in the Epic Games Launcher default folder, set repository variables `UE_5_6_ROOT`, `UE_5_7_ROOT`, and `UE_5_8_ROOT`.
6. Create a `tests-reviewed` label, and accept the `rfr-core` plugin in Claude Code when prompted.

## What is included

| Path | Purpose |
|---|---|
| `AGENTS.md`, `CLAUDE.md`, `.claude/rules/` | Instructions and rules (core plus unreal-plugin) |
| `.claude/settings.json` | Enables the `rfr-core` plugin (hooks, agents, skills) |
| `.github/workflows/tier1.yml` | Engine-free checks on GitHub-hosted runners |
| `.github/workflows/tier2.yml` | Build and test per engine version on the self-hosted runner |
| `.github/workflows/guards.yml` | Secret scan and test change guard |
| `Scripts/Verify.ps1` | The same build-and-test loop for local use and for agents |
| `.clang-format` | An approximation of Epic's style for the format-on-edit hook |
