# Logo

The Rules for Robots mark: a bound guide whose opening capital is a robot R.

| File | Use |
|---|---|
| `logo.svg` | The source. Square and full bleed, so GitHub's own crop rounds it. |
| `avatar.png` | 512 by 512, rendered from `logo.svg`, for a GitHub avatar. |
| `social-preview.svg` | Source of the repository's social preview. The title is set in Space Grotesk. |
| `social-preview.png` | 1280 by 640, rendered from `social-preview.svg` with Space Grotesk loaded. Upload it under the repository's Settings, General, Social preview. |

## Colours

| Part | Colour |

## Changing it

Edit the SVG files by hand; they have no font or tool dependency apart from the title in the social preview. Render each PNG again from its SVG at the size in the table, in a browser with Space Grotesk loaded for the social preview. Check a change at 16 pixels, in a rounded-square and a circle crop, on GitHub's light and dark pages, before accepting it.

## How it was chosen

On 2026-11-14 the maintainer chose it over four rounds of drawn options: the R with an antenna and an eye from five different ideas, then that R as the opening capital of a text, then the spine that makes the text a bound guide, then the orange from six palettes.
